Tugas 03: Inheritance & CRUD Simulation

Deskripsi Proyek:
Program ini adalah sistem manajemen data anggota Neo Culture Technology (NCT) berbasis Java. Proyek ini dibuat untuk memenuhi tugas mata kuliah Pemrograman Berorientasi Objek (PBO) dengan mengimplementasikan konsep Inheritance (pewarisan) dan simulasi database sederhana.

Fitur Utama:

    Inheritance (Pewarisan): Menggunakan kelas NCTMember sebagai Parent Class dan NeoUnit sebagai Child Class.

    Encapsulation & Constructor: Implementasi 3 tipe Constructor (Default, Partial, Full) untuk inisialisasi data anggota.

    CRUD Simulation: Simulasi operasi Database (Create, Read, Update, Delete) menggunakan sintaks SQL yang ditampilkan pada konsol.

    Management System: Mampu mengelola atribut member secara global dan spesifik per unit (NCT 127, Dream, WayV, Wish).

Struktur Kelas:

    NCTMember.java: Kelas induk yang berisi 5 atribut utama dan fungsi CRUD.

    NeoUnit.java: Kelas turunan yang menambahkan atribut spesifik unit (activeProject, status) dan metode manajemen unit.

    Main.java: Kelas eksekusi untuk menjalankan sistem dan mendemonstrasikan seluruh fungsi.

Informasi Mahasiswa:

    Mata Kuliah: PBO1

    Topik: Inheritance & OOP
